# Material 3 specification (snapshot)

Text and token data from <https://m3.material.io>, content version `2026-09-23_06-10-05`, from the site's own content JSON (`/_dsm/content/m3/<version>/<page>.json`) and token database (`/_dsm/data/dsdb-m3/<version>/<module>.json`). Converted to Markdown mechanically: page text is verbatim; images, videos and embeds appear as their alt text with a link to the original file (`[Image: alt](url)`), so they can be fetched and inspected; component status tables are omitted. Token values are filtered to the public M3 contexts: entries tagged `Platform=iOS` or `Audience=1P Baseline` (Google's own products) are left out.

Generated by `packages/m3/scripts/fetch-spec.ts`; do not edit by hand. Regenerate with `pnpm run m3-spec` in `packages/m3` (or `pnpm run m3-docs` in `apps/studio`; `--refresh` re-downloads instead of reusing `packages/m3/.cache/m3/<version>`).
