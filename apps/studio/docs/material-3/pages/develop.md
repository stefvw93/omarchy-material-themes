#### Material platforms

The Material Compose library is built in-house, so it receives the latest Material updates first. It’s the recommended platform for developing on Android.

[Image](https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fm3%2Fimages%2Fmpmhexvj-develop2.png?alt=media&token=81071026-a0eb-40e8-949c-cf13d8d89778) (links to https://m3.material.io/develop/android/jetpack-compose)

_Jetpack Compose is the recommended toolkit for building Material UI on Android. Get developer documentation, tutorials, and feature highlights to build with Material for Android using Jetpack Compose._

The Material Flutter library is actively maintained by the Flutter team and receives periodic Material updates.
