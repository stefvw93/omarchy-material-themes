# Material 3: spec exceptions

Generated by `packages/m3/scripts/generate.ts` from `packages/m3/src/interpretations.ts` (spec content version 2026-09-23_06-10-05). Do not edit.

Everything the engine draws follows Material 3, or fills a place where the spec is silent ([interpretations](m3-interpretations.md)). An exception is different: there the engine knowingly departs from what the spec says. Each one is

- a decision the user made, not a default the engine drifted into;
- backed by a precedent, preferably Google's own platforms (ChromeOS, Android) building on Material;
- controllable: a token or setting turns it off or tunes it, where it can be;
- documented in full in its interpretation (what the spec says, the choice, why) and in the feature's spec.

A new exception is an interpretation with an `exception` (`packages/m3/src/interpretations.ts`); this page lists them all.
